# 사천성

같은 그림 두 개를 두 번 이하로 꺾이는 선으로 이어 없애는 퍼즐. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나.

- 선은 다른 패를 넘을 수 없고, 판 바깥 한 줄로는 돌아갈 수 있다
- 시간 안에 판을 다 비우면 다음 단계 (단계마다 시간이 줄어든다)
- 💡 힌트 3번 · 🔀 섞기 2번 (단계마다 다시 채워짐), 막히면 자동으로 섞어 준다
- 판은 늘 끝까지 풀 수 있는 배치로만 나온다

`index.html` 을 그대로 열면 된다. 판 규칙은 `logic.js`, 화면·입력은 `game.js`.
