# 사천성

같은 그림 두 개를 두 번 이하로 꺾이는 선으로 이어 없애는 퍼즐. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나.

- 선은 다른 패를 넘을 수 없고, 판 바깥 한 줄로는 돌아갈 수 있다
- 시간 안에 판을 다 비우면 다음 단계. **단계가 오를수록 어려워진다**: 1단계는 그림 6종 · 패 32개로 시작해 8단계에 그림 20종 · 패 80개가 되고, 그 뒤로는 시간이 줄고 힌트·섞기 횟수가 줄어든다 (`logic.js` 의 `stageParams`)
- 클리어하면 **남은 시간이 보너스 점수**로 바뀐다 (1초당 10점에서 시작해 단계마다 2점씩 커져 최대 40점). 세어 가는 모습이 화면에 보이고, 누르면 건너뛴다
- 💡 힌트 · 🔀 섞기는 단계마다 다시 채워지지만 횟수는 갈수록 줄어든다 (처음엔 3번·2번). 막히면 자동으로 섞어 준다
- 판은 늘 끝까지 풀 수 있는 배치로만 나온다

`index.html` 을 그대로 열면 된다. 판 규칙은 `logic.js`, 화면·입력은 `game.js`.
